# Prompts plan par plan

Pour les générateurs qui font des clips de 5 à 10 s (Google Flow, Dreamina, Kling…). Réglages : **9:16**, durée la plus courte, qualité maximale. Nomme chaque vidéo `shot_XX.mp4`. Les textes (adresse, horaires, ABONNEZ-VOUS, pseudo) s'ajoutent au montage, pas ici.

**Astuce cohérence :** génère d'abord le shot_06 (vue d'ensemble). Fais une capture de la meilleure image, puis génère les autres vues larges en mode « image vers vidéo » avec cette capture comme référence.

**Negative prompt (le même pour tous les plans) :**

